git diff- показывает что изменилось
git log- показывает историю коммитов
git show- показывает конкретный коммит и его содержимое

log -S -ищет изменения (вставление или удаления конкретной строки)

blame- показвыет кто и каким коммитом изменял строки

git restore- Берет файл из индекса или коммита

git restore --source=...- берет версию с указанного коммита
