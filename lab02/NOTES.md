Рабочая папка- Папка на компьютере содержащая файлы, в ней хранится и изменяется проект



Индекс- промежуточная область между папкой и коммитом



Коммит- зафиксированное состояние проекта (сохранение)



GIT- система контроля версий работающая локально на компьютере. Она хранит историю проекта  но не требует интернета.



GITHUB- Это платформа для хранения гит репозиториев и совместной работы над проектами, git это инструмент для работы, а github это сервис для хранения и совместной работы над репозиториями

git status показывает текущее состояние репозитория  какие файлы изменены какие добавлены в индекс

git diff- сравнивает рабочую папку с индексом и показывает какие файлы я изменил но еще не добавил в индекс

git diff --satged- сравненивает индекс с последним коммитом юпоказывает изменения введенные в индекс и попадут в коммит.
